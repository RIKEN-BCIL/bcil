Inter-site connectivity (interactive 3D)

Example output of hcppipe_gqc (BCIL pipelines). Travelling-subjects QC: each bar is a pair of Site/Projects, bar height = number of subjects scanned at both, bar & label color = scanner model. It rotates slowly on its own; drag to rotate, scroll to zoom, hover a bar for the shared count. Requires a WebGL-capable browser with internet access (loads ECharts from a CDN). No participant-level data is shown.
